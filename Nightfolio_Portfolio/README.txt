NIGHTFOLIO PORTFOLIO WEBSITE

HOW TO OPEN:
1. Extract this ZIP file.
2. Open the Nightfolio_Portfolio folder.
3. Double-click index.html to view the website in Chrome or Edge.
4. To edit the code, open the folder in Visual Studio Code.
5. Replace Your Name, you@email.com, and social links with your own details.

FILES:
- index.html: page structure and text
- style.css: colors, layout, effects, and responsive design

This project uses HTML and CSS only. The optional Google Font import needs an internet connection; system fonts will be used if unavailable.
